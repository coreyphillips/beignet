| API reference | Generated by typedoc for every entry point. CI uploads it as the `api-docs` artifact; `npm run docs:html` builds it into `api-docs/` |

The option and event tables in the two READMEs above are generated from the code by `npm run docs:tables`, and CI fails when they are stale (`npm run docs:check`). CI also fails when a code comment cites a file that is not in the repository (`npm run docs:paths`), and when the exported API differs from its snapshot in `tests/api-snapshot/` (`npm run api:snapshot` regenerates it).
